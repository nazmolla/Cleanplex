# AI Agent (MCP) Endpoint

`POST /mcp` speaks the Model Context Protocol (Streamable HTTP).

Point an MCP client at `http://your-server:7979/mcp` to:

- List libraries and titles
- Read segments
- Check scanner status
- Queue a scan
- Delete segments
- Read settings

Like the rest of the API, it has no login — see [Security](security.md).
